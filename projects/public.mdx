---
title: "Public"
description: "Toggle project visibility"
---

Use `/public` to make a project viewable by anyone with the link — no login required.

## How to use

1. Type `/public` and press **Space**.
2. Grapple toggles public access on or off.

You can also toggle this from **Settings → Make Public** in the project editor.

## What public means

- Anyone with the project URL can view charts and data.
- Public projects are read-only — editing still requires workspace permissions.
- A banner in the editor confirms when a project is public.
