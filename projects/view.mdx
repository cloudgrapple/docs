Use `/view` to create an aggregated report — a **view** (groupset) with grouping dimensions and measures.

## How to use

1. Type `/view` and press **Space**.
2. Describe the metric you want — for example, *"revenue by month"* or *"deals won by rep"*.
3. Grapple creates a view with the right groupings and measures, then navigates you to it.

Views appear as tabs in the project editor. Switch between them to compare different aggregations.

## What you get

A view groups rows by one or more fields and calculates measures like sum, count, average, or distinct count. Date fields can be bucketed by year, quarter, month, week, or day.

Charts can be built from an existing view using **Create from View** in any chart skill.
