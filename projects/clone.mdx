Use `/copy` to create a full duplicate of the current project.

## How to use

1. Type `/copy` and press **Space**.
2. Grapple creates a copy named `{original name} ({your name}'s copy)` and opens it in a new tab.

## What's copied

The clone includes joins, fields, views, charts, filters, and materialized data — so the copy is ready to use immediately.

<Info>
  Cloning requires workspace owner or editor access, or ownership of the project.
</Info>
