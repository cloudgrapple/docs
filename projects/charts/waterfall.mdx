Use `/waterfall` to show how values build up or break down step by step, with running subtotals.

## How to use

1. Type `/waterfall` and press **Space**.
2. Describe the progression — for example, *"monthly revenue change by category"*.
3. Grapple creates the chart with cumulative subtotals.

Or pick **Create from View** to build a chart from an existing view.

## Tips

- Useful for showing how individual contributions add to a total.
- Wait for materialization to reach **up to date** before the chart loads data.
