---
title: "Export"
description: "Export raw data as a CSV"
---

Use `/export` to download your project data as a CSV file.

## How to use

1. Type `/export` and press **Space**.
2. Grapple starts a background export job.
3. You receive an email with a download link when the file is ready.

If a view tab is active, the export uses that view's aggregation. Otherwise it exports the raw materialized data.

You can also export from **Settings** in the project editor.
