Use `/add` to add a native column from a connected collection.

## How to use

1. Type `/add` and press **Space**.
2. Search for a field from your project's collections.
3. Select the field to add it as a new column.

Grapple re-materializes the project after adding a field.

<Tip>
  Fields from joined collections appear with a path prefix, like `hubspot_contacts.email`.
</Tip>
