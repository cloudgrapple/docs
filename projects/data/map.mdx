title: "Map"
description: "Map data to this project"
---

Use `/map` to join an additional collection from your Data Library to the project.

## How to use

1. Type `/map` and press **Space**.
2. Grapple opens the **Map Data** page.
3. Pick the collection to join and select the join keys on both sides.
4. Save the join.

Grapple seeds fields from the joined collection and re-materializes the project.

<Info>
  Each collection can only be joined once per project.
</Info>

## Tips

- Join related data to enrich your base collection — for example, join Contacts to Deals.
- After mapping, use `/add` to pull fields from the joined collection into your grid.
